# Málaga Guide

A mobile web app (PWA) combining two Málaga travel guides: sights, museums, galleries and shops, plus cafés, tapas bars, restaurants, rooftops and gay venues. Every place has links to Google reviews, TripAdvisor and walking directions in Apple Maps or Google Maps.

It's a plain static site with no build step. Open `index.html` or host the folder anywhere (GitHub Pages, Vercel, Netlify).
